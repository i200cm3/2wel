# Виджет amoCRM · 2wel презентация

Приватный виджет в **правой колонке сделки**: кнопка «Сформировать презентацию», статус пайплайна, ссылка, копирование / открытие.

Бэкенд (без фильтра воронки):

- `GET /api/v1/projects/{code}/amo-widget/leads/{leadId}`
- `POST /api/v1/projects/{code}/amo-widget/leads/{leadId}/issue`

После выдачи запускается тот же `presentationPipeline`, URL пишется в поле «Ссылка для презентации».

## Установка в amo

1. В кабинете 2wel → **Интеграции** создайте ключ проекта (`pk_live_…`), скопируйте его.
2. Соберите архив **строго** так (файлы в корне zip, имя `widget.zip`):

```bash
cd api && npm run zip-amo-widget
# → ../widget.zip  (и копия amo-widget.zip)
```

Не пакуйте папку `amo-widget/` целиком через Finder — иначе внутри окажется вложенная папка + `__MACOSX`, и amo отклонит архив.

3. В amo: **амоМаркет → Моё приложение → интеграция** → загрузите **`widget.zip`**.
4. Настройки виджета:

| Поле | Пример |
|------|--------|
| Базовый URL API | `https://2wel.ru` |
| Код проекта | `plaza` |
| Ключ проекта | `pk_live_…` |

5. Откройте сделку — справа блок **2wel · Презентация**.

Нужны: OAuth amo в кабинете 2wel и поле «Ссылка для презентации» на сделке.

## Обновление архива (без пересоздания интеграции)

**Не полагайся на «Выключить → Включить»** — у приватных виджетов Amo после заливки нового zip это часто «убивает» установку: блок пропадает из карточки, пока не переустановишь. Удалить интеграцию и создать заново всегда чинит — но это крайний путь.

Нормальный цикл:

1. Подними `widget.version` в `manifest.json` (иначе Amo/браузер кэшируют старый `script.js`).
2. `cd api && npm run zip-amo-widget`
3. В той же интеграции → загрузить новый `widget.zip` → **Сохранить**.
4. Открыть настройки виджета в аккаунте → ещё раз **Сохранить** (поля `api_base` / `project_code` / `api_key` иногда «отлипают» после апдейта).
5. Жёстко обновить карточку сделки (Cmd+Shift+R) или открыть сделку в новой вкладке.

Если блок всё же пропал: в списке интеграций аккаунта **отключить установку и установить снова** (не удаляя само приложение/OAuth). Полное «удалить и создать новую интеграцию» — только если и это не помогло.

## Поведение

- **Сформировать / Обновить** — выдача (или reuse) ссылки + персонализация.
- Пока `running` — виджет поллит статус каждые 4 с.
- Ссылка видна в виджете; в CRM-поле попадает после успешной сборки (как у webhook/Salesbot).

## Разработка

Файлы: `manifest.json`, `script.js`, `style.css`, `i18n/`, `images/`.  
Иконки: исходник `images/logo_source.png` (твой мастер), остальные размеры собираются из него **без чёрных полос** (прозрачные поля).  
Не перезаписывай `logo_source.png` скриптом ресайза. После правок лого — новый zip.
