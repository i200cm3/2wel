# Verify operator review against full transcript

Первый проход уже выставил недоработку оператора. Твоя задача — **перепроверить по полному транскрипту**,
действительно ли она доказана словами разговора.

На выход: ТОЛЬКО один JSON-объект без markdown, без пояснений, без хвоста.

```json
{
  "operatorReview": null
}
```

Или подтвердить / уточнить:

```json
{
  "operatorReview": {
    "miss": "",
    "detail": ""
  }
}
```

## Главное правило

Источник истины — **реплики в транскрипте**, не саммари и не формулировка кандидата.
Саммари и кандидат могут ошибаться. При сомнении — `null`.

## Когда ставить null

Ставь `null`, если хотя бы одно верно:

- в репликах **оператора** есть хотя бы одна **конкретная** альтернативная дата
  (число + месяц: «с 24 октября», «числа двадцать четвёртого», «21 ноября»)
  или конкретный предложенный номер/категория — даже если гость отказался / «подумает»;
- оператор назвал доступный вариант («есть с …», «можем с …», «попозже — с …»);
- у гостя **уже есть** бронь или путёвка («мы бронировали», «путёвка у вас с …»,
  «всё в силе», оператор ищет бронь по фамилии) — просьба про другой номер, балкон,
  трансфер или ранний заезд в такой брони не является упущенной продажей;
- оператор ответил на вопрос гостя (например: «сейчас нет, отметили в брони, решат при заезде») —
  это не недоработка;
- кандидатный miss не подтверждается транскриптом (модель первого прохода ошиблась);
- по транскрипту неясно.

Жёсткое правило: перед ответом найди в репликах оператора конкретные даты или варианты.
Если нашлось хоть одно предложение альтернативы — всегда `"operatorReview": null`.
Не требуй искать ещё варианты после отказа гостя.

Назвать только месяц («только ноябрь») без числа — это ещё не альтернатива.
Повторить даты, которые назвал **гость**, без своего предложения — тоже не альтернатива.

## Когда оставить разбор

Только если **одновременно**:

1. Гость хотел **новую** бронь (брони ещё нет) / обсуждал даты или номер.
2. Оператор мог предложить другие даты/категорию, но **не назвал ни одной конкретной**.
3. Сделка в этом звонке не закрыта.
4. Кандидатный miss по смыслу совпадает с тем, что видно в транскрипте.

Тогда:
- `miss` — до ~12 слов;
- `detail` — 1–2 предложения **по словам транскрипта** (не копируй слепо кандидата).

Не оценивай тон. Не выдумывай места, которых не называли.

## Кандидат разбора (может быть ошибочным)

miss: {{MISS}}

detail: {{DETAIL}}

## Саммари (только контекст, не доказательство)

Итог: {{OUTCOME}}

Следующий шаг: {{NEXT_STEP}}

## Транскрипт

```
{{TRANSCRIPT}}
```
