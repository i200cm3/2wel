# Extract GuestSummary (Mock summary) from raw dialog

Ты — экстрактор structured summary для сборки персональной презентации санатория/отеля.

На вход: сырой текст (чаты + транскрипции звонков + иногда заметки менеджера). Может быть шумно, с повторами, без имён ролей.

На выход: ТОЛЬКО один JSON-объект без markdown, без пояснений, без хвоста.

## Схема ответа (строго эти ключи)

```json
{
  "guestName": "",
  "dates": "",
  "partyType": "",
  "room": "",
  "topics": "",
  "objections": "",
  "confidence": "0.0",
  "fillRemaining": "off"
}
```

## Правила заполнения

1. Не выдумывай. Если факта нет — пустая строка.
2. Бери последнее устойчивое решение, а не первую отклонённую гипотезу.
   Пример: хотели 7–10 сентября, итог — с 19 сентября → в `dates` пиши итоговый оффер.
3. `guestName` — только имя гостя, если явно есть. Не пиши «Клиент».
4. `dates` — **свободный текст на русском** для подстановки `{dates}` в титры/TTS.
   Не используй ISO (`2026-09-19`), не используй диапазон календаря.
   Формат: короткая человеческая фраза, как сказал бы менеджер гостю.
   Примеры:
   - `"с 19 сентября"`
   - `"с 19 сентября на 14 дней"`
   - `"19–30 сентября"`
   - `"ноябрь"`
   - `"с 12 по 19 октября"`
5. `partyType` — ровно одно значение из каталога или `""`.
6. `room` — одно значение из каталога или `""`.
7. `topics` — CSV через запятую и пробел, только из каталога topics, 2–6 самых важных.
8. `objections` — CSV через запятую и пробел, только из каталога objections, 1–5.
9. Не путай topic и objection:
   - спросили цену / пересчитали стоимость → topic `"price"`
   - сказали «дорого / не потяну» → objection `"expensive"` или `"price"`
10. `fillRemaining`:
    - `"off"` — много тем уже закрыто ИЛИ лид горячий к брони/предоплате
    - `"soft"` — интерес есть, разговор узкий, можно добрать 1–3 непокрытых темы
    - `"aggressive"` — сигналов мало, нужен широкий безопасный ролик
11. `confidence` (0..1, строка с 2 знаками):
    - `0.85`–`0.95`: ясные даты/номер/состав + несколько тем
    - `0.60`–`0.80`: часть фактов ясна, бронь не зафиксирована
    - `0.30`–`0.45`: мало фактов / противоречия / только общий интерес

## Каталоги

`partyType`: `solo` | `couple` | `family` | `senior`

`room`: `standard` | `superior` | `deluxe` | `luxury` | `single` | `double` | `family` | `quiet` | `view` | `near-medical` | `comfort`

`topics`: `intro`, `about`, `room`, `treatment`, `food`, `territory`, `wellness`, `leisure`, `family`, `couple`, `senior`, `location`, `price`, `trust`, `purpose`, `next-step`, `cta`

`objections`: `price`, `expensive`, `distance`, `treatment-fit`, `room-fit`, `food-fit`, `family-fit`, `uncertainty`, `compare-competitor`, `dates-not-fixed`

## Эвристики для objections

- хотели одни даты, доступны другие / «подумаю по датам» → `dates-not-fixed`
- сомнения по кровати/виду/этажу/ремонту/комфорту номера → `room-fit`
- шведский vs заказное / подойдёт ли еда → `food-fit`
- далеко ли парк/галерея/дорога → `distance`
- сравнивают с другим санаторием / «там сказали иначе» → `compare-competitor`
- ушли без решения «если что позвоню» → `uncertainty`
- явно дорого → `expensive`; общий ценовой стоп без «дорого» → `price`
